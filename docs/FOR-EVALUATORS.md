# For evaluators

This repository holds the programme's texts. It does not hold a study sample.

## Read in this order

1. [STATUS.md](STATUS.md) — no public maturity stage; which documents are Draft, Proposed, or Accepted.
2. [SCOPE.md](SCOPE.md) — what the programme is not, including the Proposed status of CLRP-007.
3. [CLRP-004](../clrp/CLRP-004-epistemic-commitments.md) — what the Accepted text counts as evidence. Confirm the status in the file's front matter before citing it.
4. [validation/](../validation/) — draft status reports for the questionnaire (tier T0) and the model (tier T1 engineering verification).
5. [CLRP-006](../clrp/CLRP-006-evidence-and-validation.md) — evidence and validation. Its status in the index is Draft.

## What a catalog check is

`python3 scripts/validate-catalog.py` checks that `catalog.yaml` matches the files. A pass is a documentation check. It is not a scientific result and it is not peer review.
