# What this repository is not

- Not the public questionnaire. That instrument is [PCMS](https://github.com/SynapticFour/perceptual-cognitive-mapping-system), at [https://map.synapticfour.com](https://map.synapticfour.com). Its draft status report is tier T0.
- Not the computational library. That library is [CLM](https://github.com/SynapticFour/cognitive-landscape-model).
- Not a diagnostic instrument and not a medical device. The non-diagnostic text is [CLRP-007](../clrp/CLRP-007-non-diagnostic-commitment.md). That document's status is Proposed, not Accepted.
- Not peer review, and not an empirical sample. Validation reports in `validation/` are drafts unless a file says otherwise.
- Not a store of participant data. [SECURITY.md](../SECURITY.md) says this repository does not store participant data and does not run an assessment.

The working assumption of the programme is that cognitive traits are mostly distributed along a continuum and that fixed labels represent them poorly (CLRP-RATIONALE-001). That is an assumption, not an established finding.
